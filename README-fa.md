# دستیار هوشمند بازرگانان (نسخه ۱)

ساخته‌شده توسط Meta Commerce. این بسته فقط فایل‌های عمومی را دارد و **متن جزوه و منابع خصوصی در آن نیست**.

## محتوای پوشه
- `index.html`: اپ اصلی (مشاور اینکوترم، چک‌لیست مدارک، پیش‌فاکتور، ماشین‌حساب فرمولی، ابزارهای آماده)
- `chambers/index.html`: اتاق‌های بازرگانی کشورها
- `manifest.webmanifest` و `sw.js` و `icons/`: نصب روی گوشی (PWA) و کار آفلاین
- `.github/workflows/pages.yml`: انتشار خودکار روی GitHub Pages
- `.github/workflows/android.yml`: ساخت فایل APK اندروید (دستی)
- `mobile/`: تنظیمات Capacitor برای اپ اندروید

## راه ۱: فقط آپلود روی هر هاست (ساده‌ترین)
همه فایل‌های این پوشه را در ریشه یک هاست با HTTPS آپلود کنید (cPanel، Netlify، Cloudflare Pages و غیره). بعد آدرس را باز کنید.
- **اندروید (Chrome):** منوی سه‌نقطه ← «Install app / افزودن به صفحه اصلی».
- **آیفون (Safari):** دکمه Share ← «Add to Home Screen».

## راه ۲: GitHub Pages (رایگان)
1. یک مخزن **جدید** بسازید (پیشنهاد: Private تا مطمئن شوید).
2. همه فایل‌های این پوشه (به‌همراه پوشه `.github`) را در شاخه `main` آپلود کنید.
3. در Settings ← Pages، منبع را روی «GitHub Actions» بگذارید.
4. بعد از اجرای Actions، آدرس سایت نمایش داده می‌شود.
(اگر Pages در حساب شما برای مخزن خصوصی فعال نیست، مخزن را عمومی کنید؛ این بسته چیزی محرمانه ندارد.)

## راه ۳: فایل APK اندروید
1. پوشه را در GitHub بگذارید.
2. تب Actions ← «Build Android APK (debug)» ← Run workflow.
3. بعد از پایان، فایل `app-debug.apk` را از بخش Artifacts دانلود کنید.
4. روی گوشی نصب کنید (نیاز به اجازه «نصب از منبع ناشناس»).
- این نسخه **آزمایشی (debug)** است و برای انتشار در گوگل‌پلی باید امضا و ساخته شود.
- این روند در محیط من اجرا نشده و فقط تنظیمات آن آماده است؛ اگر اولین اجرا خطا داد، متن خطا را بفرستید.

## تغییر لینک بازخورد
در `index.html` عبارت `metateam.am/contact.php` را (در بخش «ارسال بازخورد») با لینک فرم گوگل خودتان جایگزین کنید.

## یادآوری
- بعد از هر تغییر در فایل‌ها، در `sw.js` عدد نسخه (`trader-v1`) را بالا ببرید تا کاربران نسخه جدید را بگیرند.
- لینک اتاق‌ها را هر چند ماه یک بار بررسی کنید.
- متن جزوه و نسخه دستیار هوشمند در پوشه جدا (`PRIVATE`) است؛ هرگز در این مخزن نگذارید.
